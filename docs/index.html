WellPaiD Trader

A modular personal AI agent for trading research, strategy development and paper trading — with strict safety controls.

Python 3.11–3.14 stdlib-only SQLite 110+ tests CI: ubuntu + windows

Research-only. Live trading does not exist in this project: no broker order APIs, no exchange trading APIs, no wallet, no deposits or withdrawals. Paper trading uses simulated money behind a risk veto.

Quick start

git clone https://github.com/wellpaidwilliam-crypto/wellpaid
cd wellpaid
python -m agent.core.main
# python -m unittest discover tests -v

What it does

Tool-driven agent

Calculator, memory, tasks, market data, backtest, paper account and document tools behind one safe registry. No shell execution, by design.

Risk veto

Every paper proposal passes quantity, notional, exposure, loss and drawdown checks. Rejections explain why.

Read-only market data

Global stocks via Stooq, crypto via Coinbase public endpoints. No keys, no trading endpoints.

Honest backtests

SMA research with fees/slippage modeling, labeled HISTORICAL — never presented as prediction.

Document tools

Read xlsx, docx, PDF and DXF drawings with the standard library. Sandboxed paths, capped sizes.

Authenticated API

Bearer-token localhost API for status, account, risk and tools. Fail-closed without a token.

Safety model

  • Trading disabled by default (TRADING_ENABLED=false); validation is fail-closed.
  • AI/tool requests cannot bypass RiskEngine — tested explicitly.
  • Memory refuses credential-like content; logs redact secrets including format args.
  • Paper engine: no margin, no naked shorts, balance-checked fills.
